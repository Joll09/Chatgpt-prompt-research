# Chatgpt-prompt-research
REFER TO PROMPT

## Chat folders

Each new chat gets its own numbered folder. `chat-01/` is Chat 1, `chat-02/` is Chat 2, and numbering continues from there.

1. Read this README, the repository file list, and the prior chat folders. Verify your assigned folder, the last completed checkpoint, and the next action.
2. Treat prior chat folders as read-only. Write new records only in your assigned folder. Preserve all existing files, text, and history. Add corrections and revisions as new files that link to the earlier records.
3. Save each phase pass in a new file, such as `phase-01-pass-01.md`. Record the handbook version, work completed, evidence, verification, decisions, and open items. Use a new filename for each repeat.
4. Before requesting a new chat, add a handoff README in your own folder. Record why a handoff is needed, any actual limit reached, the work completed or underway, the handbook used, and the next action. Give each additional handoff its own filename.
5. Reserve the immediately following chat folder with an empty `.gitkeep`. This is the reservation marker. A folder containing only the marker is ready for its assigned chat. Preserve the marker and verify that the handoff and reservation are visible on GitHub.
6. In the next chat, read the previous handoff and handbook before starting work. Save the current handbook and all new work in your assigned folder.

This repository is public. Use it for records suitable for publication.
